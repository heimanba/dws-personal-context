# 验证契约记录

本文件只记录可复用的接口语义和验证方法，不保存真实账号、人员、会话、文档标识、内部业务链接或个人操作时间线。

## 采集与身份

- 目录发现不证明全集；只读取经明确判型的单聊正文。
- 单聊文件只接受 meta.format=dws-personal-context-dialogues、schemaVersion=2 且包含完整 state 的正式格式；改名前写入的同类文件只读兼容。多源文件只接受 schemaVersion=3。
- 同账号更新和合并核对稳定身份；不提供文件升级、身份补全、旧命令别名或自动改写回退。
- 同目标采集有文件锁、原子保存、权限限制和失败范围账本。
- 逐会话消息读取彼此独立、无跨会话依赖，可按会话有界并发；上游未公布并发上限，故钳在小并发并保留串行落盘顺序与逐会话检查点。
- `+search-msg --page-all` 单次调用在服务端连续翻页：满页预算（40 页）实测 55–70s，未满页为秒级；据此把搜索调用的超时上限按页预算缩放，目录与其余调用不变。翻页沿真实游标链式串行，上游无并行分页接口。

## 发布

- 用户明确要求后才发布 digest；check 与 dry-run 不产生线上写入。
- 在个人文档空间解析固定文件夹，不把钉盘挂载点误认为文档根目录。
- 创建前按账号与标题保存 pending 回执；收到响应后立即保存文档 ID，再做全文核验。并发、重入和中断后恢复不得重复调用创建。
- 业务错误回执独立于进程退出码解析；部分成功或未知状态保留 ID、步骤和禁止重放标记。
- 全文核验可忽略 Markdown 格式差异，但不能忽略正文、链接、代码或表格内容差异；引用定义单独核对，行列不齐的表格拒绝非精确匹配。
- 更新要求明确目标和授权；覆盖仅允许含 `完整取证见本地 digest` 的发布副本，不提供其他标记的识别分支。
